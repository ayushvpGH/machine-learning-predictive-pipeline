# Supervised Machine Learning & Predictive Modeling Pipeline

## Project Overview
This repository contains an end-to-end supervised machine learning pipeline implemented in Python. The project covers data preprocessing, feature normalization, cross-validation, and performance evaluation for classification and regression tasks.

## Key Technical Implementation
- **Data Preprocessing & Scaling:** Cleaned heterogeneous datasets, handled missing values, and applied feature scaling to ensure uniform model weighting.
- **Model Training & Hyperparameter Tuning:** Developed robust classification and regression pipelines using `scikit-learn`.
- **Rigorous Evaluation:** Implemented k-fold cross-validation and evaluated model performance using multi-class and binary metrics including ROC-AUC, Precision-Recall, F1-Score, and Mean Squared Error.
- **Reproducible Workflow:** Structured using documented Jupyter Notebooks (`.ipynb`) to ensure clarity and transparent feature interpretation.

## Tech Stack
- **Language:** Python
- **Libraries:** Scikit-Learn, Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook / RStudio

## Repository File Structure
- `machine_learning_pipeline.ipynb` — Full source code notebook containing data ingestion, training, tuning, and evaluation metrics.
